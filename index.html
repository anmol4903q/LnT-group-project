About This Website

This website is a simple and clean portfolio project created as a part of the L&T EduTech Program. Our goal was to design a minimal and user-friendly interface using only HTML, CSS, and a little JavaScript.

The website features a sliding profile section showcasing three team members and their creative interests. Each slide highlights a different skill—UI/UX design, visual editing, and singing—showing how design and storytelling can work together in a neat layout.

We focused on clean structure, modern styling, smooth transitions, responsive layout, and aesthetic design. This project helped us learn how to build and present a webpage from scratch.
